# Digital-Library-Management-System
** A simple Digital Library Management System developed using Java.  
The system allows users to manage books, borrowers, and the borrowing/returning processes.  
It is built based on Object-Oriented Programming (OOP) principles such as Encapsulation, Inheritance, Interfaces, and Polymorphism.
** Features :
- Add a new book (electronic or physical)
- Register a new borrower
- Lend a book to a borrower
- Return a borrowed book
- Search for books or borrowers
- View borrowed books for each borrower
** How to Run :
- Clone the repository using Git:
   git clone https://github.com/INES-BEGGAS/Digital-Library-Management-System.git
- Open the project in a Java-supported IDE
- Navigate to the file:
   Main.java
- Run Main.java
